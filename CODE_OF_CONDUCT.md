# Código de conduta

Queremos um espaço respeitoso e acolhedor. Ao participar, você se compromete a:

- tratar todas as pessoas com respeito, sem assédio, discriminação ou ataques pessoais;
- aceitar críticas construtivas e focar no que é melhor para o projeto;
- não publicar dados pessoais de terceiros nem segredos.

Comportamentos inaceitáveis podem levar a edição ou remoção de comentários, bloqueio e banimento.
Para denunciar, use **Security → Report a vulnerability** (canal privado) ou contate quem mantém o repositório.
Adaptado do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
